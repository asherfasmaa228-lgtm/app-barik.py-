# ⏱️ Barik Time Management Platform 
### An AI-Powered Productivity Ecosystem for International & Exchange Students

## 📌 Project Overview
**Barik Platform** is an intelligent, highly localized productivity and time-management web application designed to help international students—especially those adjusting to new cultural environments like South Korea—balance their academic schedules, religious duties, and mental well-being. Built using **Python and Streamlit**, this platform solves the core logistical challenges faced by exchange students through automated time-tracking and structured scheduling.

## 🛠️ Core Features

*   **📅 AI Task Planner & Tracker:** A dynamic interface that allows students to input their daily academic tasks, track completion percentages, and visualize their progress through interactive progress bars.
*   **🕌 Prayer Time & Localization Engine:** A specialized module tailored for Muslim students abroad, providing real-time prayer schedule adjustments based on global geographical coordinates to ensure smooth balance between spiritual practices and university lectures.
*   **📚 Quranic Scholar Search Framework:** An integrated search tool that leverages programmatic data parsing to help students read, search, and contemplate specific Islamic texts directly within their study dashboard.
*   **💡 Integrated EdTech Shortcuts:** Embedded direct navigation interfaces linking students to top global self-learning platforms such as **MIT App Inventor, Sejong Institute, and Duolingo** to encourage continuous self-education.
*   **📝 Asynchronous Digital Notebook:** A customized database utilizing Streamlit session states that allows students to log daily academic thoughts, exam dates, and personal reviews, sorting them dynamically from newest to oldest.

## 💻 Tech Stack & Architecture
*   **Framework:** Streamlit (Dynamic Session State Architecture)
*   **Core Logic:** Python 3.10+ (Asynchronous loops, DateTime parsing, and structural data components)
*   **Styling:** Custom Embedded HTML/CSS injections for responsive mobile and web layouts.
